Qual versão é esta

Esta é o sérum antimanchas de vitamina C (30 ml). A Garnier tem outros produtos de vitamina C com nomes parecidos, como um gel de limpeza; confirma que diz "sérum" no título.

Como usar

  1. Aplica algumas gotas no rosto limpo e massaja suavemente.
  2. Evita o contorno dos olhos, como indica a marca.
  3. Por cima, o teu creme de rosto.
  4. Se o usas de manhã, termina com protetor solar: sem ele, as manchas voltam.

Perguntas frequentes

Como usar o sérum de vitamina C da Garnier?

Algumas gotas no rosto limpo, massajando, longe do contorno dos olhos; depois o creme.

O sérum Garnier vitamina C usa-se de manhã ou à noite?

Pode usar-se em qualquer altura; de manhã, sempre com protetor solar por cima.

Para que serve o sérum Garnier vitamina C?

Para reduzir visivelmente as manchas escuras e dar luminosidade, segundo a marca.

O sérum Garnier serve para homem?

Sim, a marca indica-o para todos os tipos de pele.
